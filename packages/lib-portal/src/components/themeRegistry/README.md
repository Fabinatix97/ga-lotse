# Using Joy UI with the App Router

This folder contains a custom `ThemeRegistry` component that combines the Emotion `CacheProvider`, Joy UI's `CssVarsProvider` and the `useServerInsertedHTML` hook from `next/navigation`.

- Docs: https://mui.com/joy-ui/integrations/next-js-app-router/
- Example app: https://github.com/mui/material-ui/tree/03b962b622a19f1f885ebdfed53fa2d49ad99bdd/examples/joy-ui-nextjs-ts
- Realeted issue: https://github.com/emotion-js/emotion/issues/2928
